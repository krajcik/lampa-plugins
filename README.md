# Установить плагины Lampa

Здесь хранятся наши внешние плагины. Каждый устанавливается отдельным JS-файлом;
сборщик, зависимости и собственный сервер не нужны.

## Что получите

`sports.js` добавляет на главную ряды NHL, NBA, UFC, Formula 1 и NASCAR Cup.
Виды включаются в настройках «Спорт без спойлеров».
Расписание берётся из ESPN, записи ищутся через настроенный парсер Lampa
и публичный индекс Lampa.app. Глобальные настройки парсера не меняются.
На главной показываются только события с заранее найденной записью;
проверка доступности выполняется при загрузке ряда и кешируется на 10 минут.

Один уикенд F1 — одна карточка с сессиями внутри. Один турнир UFC — одна карточка
с полным турниром, основным кардом и прелимами. У каждой части указано,
найдена ли запись; недоступные части не запускаются. Счёт, результаты, обзоры и кадры трансляций
не выводятся. Название события, дата и время остаются видимыми.

## Предусловия

- Lampa 3.x с ContentRows, Maker и Parser.
- Настроенный парсер Jackett/JacRed или Prowlarr, индексирующий спортивные записи.
- Работающий торрентный плеер Lampa: внешний клиент Android или TorrServer.
- Сетевой доступ устройства к ESPN и парсеру.

## Шаги

1. В Lampa откройте «Настройки → Расширения → Добавить плагин».
2. Вставьте адрес целиком, с завершающим `#`:

   ```text
   https://krajcik.github.io/lampa-plugins/sports.js#
   ```

3. Перезапустите Lampa и откройте главную.
4. В «Настройки → Спорт без спойлеров» выберите виды спорта. После изменения
   повторно откройте главную.
5. Выберите событие; у F1/UFC затем выберите сессию или часть трансляции.
   Плагин передаёт заранее найденную запись штатному торрентному плееру.
6. Для выбора качества или альтернативной записи удерживайте OK на карточке.
   Карточка «Ранее» открывает выбор месяца за последний год.

## Проверка результата

На главной появляются только включённые спортивные ряды. События идут от новых
к старым, F1/UFC сгруппированы. Выбор записи должен привести к настоящему видео
и звуку; загрузка списка сама по себе воспроизведение не подтверждает.

Тесты логики и синтаксиса:

```sh
npm test
```

## Ограничения

- Наличие события в расписании не означает наличие раздачи. События без
  совпадения не показываются на главной. Если ряд пуст, можно открыть архив
  и выбрать более ранний месяц. Проверка метаданных не гарантирует живых сидов.
- RU выбирается по описанию раздачи; реальная звуковая дорожка не определяется
  до запуска. При отсутствии RU возможна запись на другом языке.
  Дорожку внутри файла выбирает внешний плеер. Если он открыл другой язык,
  переключите на русский в его меню аудио.
- ESPN не даёт названия сегментов UFC в проверенном scoreboard. Время частей
  помечается неизвестным, рядом указано начало турнира. У F1 время берётся
  из каждой сессии, а не из начала уикенда.
- NASCAR пока включает Cup. Другие серии не включены в этот источник.
- Внешний торрентный клиент может показать собственный список файлов.
  Плагин очищает передаваемое название, но не меняет интерфейс других приложений
  и само содержимое видео.
- ESPN и публичные парсеры — внешние сервисы; их доступность и полнота меняются.

## Если не помогло

«Расписание недоступно»: нажмите карточку для повторной загрузки месяца.

«Парсер недоступен»: проверьте «Настройки → Парсер» и поиск обычного торрента.
Плагин не меняет адреса, ключи, плеер или настройки TorrServer.
