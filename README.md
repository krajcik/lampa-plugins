# Установить плагины Lampa

В репозитории хранятся наши внешние плагины. Каждый устанавливается отдельным
JS-файлом; сборщик и JS-зависимости не нужны. Спортивный поиск использует
отдельный сервер Jackett.

## Что получите

`sports.js` 0.4.0 дополняет существующий раздел «Спорт» (`cub_sport`).
На главную страницу он не добавляет ряды и не загружает спортивные данные.

Внутри «Спорта» сохраняются эфирные карточки с обложками. Календари NHL, NBA,
UFC, Formula 1, NASCAR Cup, Лиги чемпионов UEFA и АПЛ загружаются независимо в фоне и появляются по мере
готовности. Можно выбрать месяц за последний год. F1 объединён по уикендам,
UFC — по турнирам. На карточках командных событий видны эмблемы команд,
дата и время; обложки соответствуют виду спорта. Счёт и результаты не выводятся.

**Торренты не ищутся до выбора события.** Выбор открывает штатный экран поиска
торрентов с редактируемым запросом, списком раздач и фильтрами. Плагин не выбирает
раздачу и не запускает плеер: нужный файл выбирает пользователь.

## Предусловия

- Lampa 3.x со встроенным разделом «Спорт», Component, Layer и Parser.
- Отдельный Jackett для спорта, по умолчанию `https://jackett.home.lurno.ru`,
  и его API-ключ. Общий парсер фильмов/сериалов менять не требуется.
- Работающий торрентный плеер Lampa для запуска выбранного пользователем файла.
- Доступ устройства к CUB, ESPN и настроенному парсеру.

## Шаги

1. В Lampa откройте «Настройки → Расширения → Добавить плагин».
2. Вставьте URL целиком, с завершающим `#`:

   ```text
   https://krajcik.github.io/lampa-plugins/sports.js#
   ```

3. После обновления перезапустите Lampa: это убирает старые регистрации рядов 0.2.x.
4. Откройте «Настройки → Спорт · записи». Адрес спортивного Jackett уже задан;
   в «API-ключ спортивного парсера» введите ключ из его панели. Поле ввода скрыто,
   ключ сохраняется отдельно в Lampa и не входит в опубликованный JS.
   Глобальные `jackett_url`, `jackett_key`, Prowlarr и выбор общего парсера не меняйте.
5. Откройте существующий раздел «Спорт» в боковом меню.
6. Выберите событие, а для F1/UFC — нужную сессию или часть турнира.
7. В списке торрентов нажмите поле текущего запроса → «Указать название»,
   чтобы изменить поиск. Стандартные варианты запроса и фильтры остаются доступны.
8. Выберите нужную раздачу самостоятельно. Для прямого эфира поддерживаемой
   карточки CUB удерживайте OK и выберите «Прямой эфир».

Для командных календарей запрос содержит сезон, обе команды и дату матча;
для NHL/NBA дата берётся в America/New_York. Футбольные клубы получают
распространённые русские имена. F1 ищет уикенд по году и названию Гран-при;
UFC — турнир. Название выбранной части в запрос не добавляется: запись может
лежать внутри Full Event или пакета уикенда. NASCAR ищет Cup по дате гонки.
Пакеты и неоднозначные варианты сохраняются для ручного выбора. У CUB-карточек
без структурированных команд начальный запрос шире — по виду спорта и дню;
его можно уточнить. Неизвестные алиасы клубов/Гран-при тоже могут потребовать
редактирования. В «Популярном» у спорта сначала идут раздачи с положительным
числом сидов, затем русский язык и качество; другие способы сортировки
сохраняют штатное поведение. Плеер автоматически не запускается.

Спортивная метка сохраняется при редактировании строки поиска: такой запрос
продолжает идти в спортивный Jackett. Фильмы, сериалы и остальные поиски
передаются штатному парсеру без подмены настроек. Ошибка спорта или отсутствие
его ключа не переключает запрос на общий парсер. Для холодной проверки
Cloudflare у спорта отдельный таймаут 120 секунд; ошибка показывается явно.
Поздние ответы после закрытия экрана игнорируются.

В «Настройки → Спорт · записи» можно отключить ненужные календари. Изменения
применяются при следующем входе в раздел.

## Проверка результата

Главная открывается без запросов нашего плагина. При входе в «Спорт» страница
остаётся доступной для навигации, пока приходят календари. Поисковых запросов
торрентов до выбора события нет; после выбора открывается список, а не видео.

```sh
npm test
```

## Источники и ограничения

- Встроенный плагин CUB: `https://cub.black/plugin/sport`; расписание:
  `https://cub.black/api/sport/get` или то же API на активном зеркале CUB.
  Это небольшой список ближайших эфиров, не полный архив выбранных лиг.
- Дополнительные календари: публичный ESPN scoreboard. Кеш — 10 минут;
  запросы закрытого раздела отменяются. Строки появляются независимо,
  карточки и изображения загружаются постепенно.
- Обложки — `static.deepstream.in`, как у CUB; эмблемы — из данных ESPN.
  Изображения служат оформлением вида спорта, не кадрами конкретного матча.
- Спортивные запросы используют только отдельный Jackett из настроек плагина.
  Обычный поиск использует прежние настройки Lampa; API-ключ спорта не копируется
  в общие ключи и не подставляется в другие запросы.
  Наличие события в календаре не гарантирует раздачу или живых сидов.
- Время частей UFC в проверенном ESPN API не подписано: оно помечается неизвестным.
- NASCAR включает Cup. Другие серии этим календарём не охватываются.
- Текущая интеграция проверяется под контракт Lampa 3.3.8 и CUB Sport 1.1.1.
  При изменении встроенного компонента потребуется повторная проверка.
