# Установить плагины Lampa

В репозитории хранятся наши внешние плагины. Каждый устанавливается отдельным
JS-файлом; сборщик и JS-зависимости не нужны. Спортивный поиск использует
отдельный сервер Jackett.

## Интерфейс · рейтинги — 0.1.3

`interface.js` убирает TMDB и выводит **IMDb** и **КП** на постерах в списках
и на полной странице фильма/сериала. На постерах рейтинги стоят внизу справа
один под другим: IMDb, КП, затем MS, если MyShows добавил свою оценку.
Фон — чёрный с прозрачностью 50%, как у штатного TMDB. Плагин только меняет
положение существующей MS-плашки и не обращается к MyShows за данными.
Счётчики серий и показатели сообщества CUB сохраняются. Исходные данные и `vote_average` не переписываются.
В полной карточке постер закреплён сверху. Многострочный блок переводов с
флагами скрыт; только английское название показано рядом с годом и страной,
без дополнительной строки. Используется родное английское или альтернативное
US-название из готовых данных карточки, без новых запросов. Дубликат основного
заголовка не выводится. Поздние названия и панель MyShows не сдвигают постер вниз.
Если доступна только одна оценка, показывается только она. Отсутствующая оценка
не заменяется цифрой TMDB.

Сначала используются готовые оценки карточки и метаданные CUB по точному TMDB ID.
КП приходит из `kp_rating` CUB. Для отсутствующей IMDb-оценки работает домашний
резервный источник `https://imdb.home.lurno.ru` с официальным ежедневным набором
IMDb. [Python-сервис и установка](services/README.md). Личные API-ключи не нужны,
секретов и самого набора данных в репозитории нет. Домашний резерв доступен в LAN.

Ссылка установки:

```text
https://krajcik.github.io/lampa-plugins/interface.js#
```

Обработка начинается после `appready`, повторная загрузка не добавляет
обработчики ещё раз. Запросы идут только для постеров в области экрана,
не более двух одновременно; одинаковые карточки разделяют результат.
IMDb ID берётся из карточки, метаданных CUB либо штатного TMDB external_ids,
без поиска по похожему названию. Несовпадающие ID отбрасываются. Люди, коллекции
и эпизоды исключены. Кеш содержит до 500 ключей: полная пара — на 24 часа,
неполный результат — на час, сетевая ошибка — на минуту. Поздний ответ не меняет
удалённую или переиспользованную карточку. Нужны обычная разметка Lampa 3.3.8
и IntersectionObserver.

Проверки: `npm test` включает JS и сервис; `tests/interface-layout.html` проверяет
геометрию столбика, позднее появление MS и сохранность счётчиков в браузере.
`tests/card-layout.html` проверяет неподвижность постера при поздних названиях,
загрузке флагов, появлении MyShows и длинных строках.
Для компоновки MS используется CSS `:has()` (Chromium/WebView 105+).
Браузерная проверка не заменяет
установку на TV; сторонние темы могут потребовать отдельной проверки.

## Что получите

`sports.js` 0.6.1 дополняет существующий раздел «Спорт» (`cub_sport`).
На главную страницу он не добавляет ряды и не загружает спортивные данные.

Внутри «Спорта» сохраняются эфирные карточки с обложками. Календари NHL, NBA,
UFC, Formula 1, NASCAR Cup, Лиги чемпионов UEFA и АПЛ загружаются независимо в фоне и появляются по мере
готовности. Можно выбрать месяц за последний год. F1 объединён по уикендам,
UFC — по турнирам. На карточках командных событий видны эмблемы команд,
дата и время; обложки соответствуют виду спорта. Счёт и результаты не выводятся.

**Торренты не ищутся до выбора события.** Выбор открывает штатный экран поиска
торрентов с редактируемым запросом, списком раздач и фильтрами. Плагин не выбирает
раздачу и не запускает плеер: нужный файл выбирает пользователь.

## Предусловия

- Lampa 3.x со встроенным разделом «Спорт», Component, Layer и Parser.
- Отдельный Jackett для спорта, по умолчанию `https://jackett.home.lurno.ru`,
  и его API-ключ. Общий парсер фильмов/сериалов менять не требуется.
- В этом Jackett настроены RuTracker, NoNaMe ClubL, RGFootball и RuTor. Для
  NoNaMe ClubL нужна cookie-сессия, для RGFootball — аккаунт; RuTor публичный.
- Работающий торрентный плеер Lampa для запуска выбранного пользователем файла.
- Доступ устройства к CUB, ESPN и настроенному парсеру.

## Шаги

1. В Lampa откройте «Настройки → Расширения → Добавить плагин».
2. Вставьте URL целиком, с завершающим `#`:

   ```text
   https://krajcik.github.io/lampa-plugins/sports.js#
   ```

3. После обновления перезапустите Lampa: это убирает старые регистрации рядов 0.2.x.
4. Откройте «Настройки → Спорт · записи». Адрес спортивного Jackett уже задан;
   в «API-ключ спортивного парсера» введите ключ из его панели. Поле ввода скрыто,
   ключ сохраняется отдельно в Lampa и не входит в опубликованный JS.
   Глобальные `jackett_url`, `jackett_key`, Prowlarr и выбор общего парсера не меняйте.
5. Откройте существующий раздел «Спорт» в боковом меню.
6. Выберите событие. Для NHL/NBA/ЛЧ/АПЛ доступны «Полная запись»,
   «Обзор матча» и «Обзор игрового дня»; для F1/UFC — сессия или часть турнира.
7. В списке торрентов нажмите поле текущего запроса → «Указать название»,
   чтобы изменить поиск. Стандартные варианты запроса и фильтры остаются доступны.
8. Выберите нужную раздачу самостоятельно. Для прямого эфира поддерживаемой
   карточки CUB удерживайте OK и выберите «Прямой эфир».

Поиск объединяет четыре трекера. Категории задаются отдельно: спорт5060 для
RuTracker/RGFootball, форум соответствующего спорта для NNM и Other8000
для RuTor. Ошибка одного источника не удаляет результаты остальных; плагин
сообщает, какие трекеры не ответили. При успехе всех источников без раздач
показывается штатная пустая выдача.

Для командных календарей запрос RuTracker содержит сезон, обе команды и дату матча;
для NHL/NBA дата берётся в America/New_York. Футбольные клубы получают
распространённые русские имена. F1 ищет уикенд по году и названию Гран-при;
UFC — турнир. Название выбранной части в запрос не добавляется: запись может
лежать внутри Full Event или пакета уикенда. NASCAR ищет Cup по дате гонки.
Пакеты и неоднозначные варианты сохраняются для ручного выбора. У CUB-карточек
без структурированных команд начальный запрос шире — по виду спорта и дню;
его можно уточнить. Для NNM/RuTor командные события ищутся шире — по лиге,
году и дню, поскольку имена команд и даты оформляются по-разному; выдача
может включать другие матчи того же дня. RGFootball использует английские
имена команд, а F1 ищет по-русски. Ручная правка запроса применяется ко всем источникам
вместо автоматически составленных запросов. Неизвестные алиасы клубов/Гран-при тоже могут потребовать
редактирования. В «Популярном» у спорта сначала идут раздачи с положительным
числом сидов, затем русский язык и качество; другие способы сортировки
сохраняют штатное поведение. Плеер автоматически не запускается.

Спортивная метка сохраняется при редактировании строки поиска: такой запрос
продолжает идти в спортивный Jackett. Фильмы, сериалы и остальные поиски
передаются штатному парсеру без подмены настроек. Ошибка спорта или отсутствие
его ключа не переключает запрос на общий парсер. Для холодной проверки
Cloudflare у спорта отдельный таймаут 120 секунд; ошибка показывается явно.
Поздние ответы после закрытия экрана игнорируются.

Обзоры ищутся отдельно от полных записей. Для NHL/NBA обзор матча может
лежать в подборке Highlights/Condensed Games за день: матч выбирается в списке
файлов раздачи. Для футбола запрос обзора матча включает команды; обзор дня
ищется без команд. На RGFootball обзор дня ЛЧ ищется по дате выпуска —
следующий день, а Match of the Day АПЛ — по дате игрового дня. Русский комментарий сохраняет приоритет, когда он
указан в названии; свежие обзоры NBA и отдельного футбольного матча
в проверенных торрентных каталогах могут отсутствовать.

Запрос RuTracker сам по себе не гарантирует точную дату: адаптер заменяет
пунктуацию шаблонными символами. Для автоматического поиска обзоров проверяется
дата в названии; у NHL «за DD.MM.YYYY» важнее даты выхода. Пакеты с диапазоном
дат и раздачи с нераспознанной датой сохраняются. Повтор одного и того же
Guid на одном трекере объединяется, альтернативные раздачи остаются. При
ручном редактировании запроса автоматическое ограничение даты снимается.

В «Настройки → Спорт · записи» можно отключить ненужные календари. Изменения
применяются при следующем входе в раздел.

## Проверка результата

Главная открывается без запросов нашего плагина. При входе в «Спорт» страница
остаётся доступной для навигации, пока приходят календари. Поисковых запросов
торрентов до выбора события нет; после выбора открывается список, а не видео.

```sh
npm test
```

## Источники и ограничения

- Встроенный плагин CUB: `https://cub.black/plugin/sport`; расписание:
  `https://cub.black/api/sport/get` или то же API на активном зеркале CUB.
  Это небольшой список ближайших эфиров, не полный архив выбранных лиг.
- Дополнительные календари: публичный ESPN scoreboard. Кеш — 10 минут;
  запросы закрытого раздела отменяются. Строки появляются независимо,
  карточки и изображения загружаются постепенно.
- Обложки — `static.deepstream.in`, как у CUB; эмблемы — из данных ESPN.
  Изображения служат оформлением вида спорта, не кадрами конкретного матча.
- Спортивные запросы используют только отдельный Jackett из настроек плагина.
  Обычный поиск использует прежние настройки Lampa; API-ключ спорта не копируется
  в общие ключи и не подставляется в другие запросы.
  Наличие события в календаре не гарантирует раздачу или живых сидов.
- Время частей UFC в проверенном ESPN API не подписано: оно помечается неизвестным.
- NASCAR включает Cup. Другие серии этим календарём не охватываются.
- Текущая интеграция проверяется под контракт Lampa 3.3.8 и CUB Sport 1.1.1.
  При изменении встроенного компонента потребуется повторная проверка.
